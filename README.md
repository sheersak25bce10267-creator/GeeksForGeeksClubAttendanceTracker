# Attendance Tracker

A full-stack web application built to track and manage club participant attendance. 

## Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite (built-in, serverless)
* **Frontend:** HTML5, CSS3 (Mobile-Responsive Flexbox design)

## Core Features
* Register new participants with unique IDs.
* Toggle attendance status (Present/Absent).
* Real-time dashboard calculating total attendance metrics.
* Mobile-responsive UI preventing table overflow on smaller screens.

## How to Run Locally
1. Ensure Python is installed on your machine.
2. Clone this repository or extract the ZIP file.
3. Open your terminal in the project directory.
4. Install Flask if you haven't already:
   `pip install flask`
5. Run the application:
   `python app.py`
6. Open your web browser and navigate to `http://127.0.0.1:5000`

*Note: The repository includes a pre-initialized `attendance.db` file with test data for immediate review.*
